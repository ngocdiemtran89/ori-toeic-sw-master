🔑 4 BƯỚC NHẬN GOOGLE GEMINI API KEY MIỄN PHÍ (DÀNH CHO HỌC VIÊN)
1

Truy cập Google AI Studio

Dùng trình duyệt (Chrome/Safari) đăng nhập vào đường link: https://aistudio.google.com/ bằng tài khoản Gmail cá nhân của bạn.

2

Nhấn vào nút "Get API key"

Tại thanh menu bên trái (hoặc góc trên bên phải màn hình), nhấn vào nút màu xanh có chữ "Get API key".

3

Tạo mới API Key

Nhấn nút "Create API key" -> Chọn "Create API key in new project". Google sẽ tạo mã chỉ trong 3 giây.

4

Sao chép và Lưu trữ

Bấm nút Copy để sao chép chuỗi ký tự API Key. Chuỗi này thường có dạng:

AIzaSyB3X... (chuỗi ký tự bảo mật cá nhân)
